文献伴读跨平台预览版，内置 PDF/OCR 运行环境。请选择对应系统的 ZIP，完整解压后运行。

- Windows x64：解压后打开 `PaperCompanion.exe`，保留同目录的全部文件。
- Mac Apple Silicon（M 系列）：下载 `mac-arm64.zip`，将文献伴读.app 拖到应用程序。
- Mac Intel：下载 `mac-x64.zip`。

首次使用在设置中配置自己的模型服务。翻译和问答可分别使用 Qwen-MT-Flash、DeepSeek，也可使用已安装并登录的 Codex CLI。软件不附带 API Key 或个人文献。

这是未经商业代码签名及 Apple 公证的预览版本，系统可能提示未知开发者。macOS 原生 WidgetKit 小组件暂不随通用版分发；两个系统均提供应用内悬浮阅读组件。自动测试不等于所有系统版本的人工验收，请反馈系统版本和复现步骤。
